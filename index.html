วิธีนำไฟล์ขึ้น GitHub Pages

ขั้นตอนการเปิดใช้งานเว็บไซต์ portfolio ออนไลน์ฟรี

ขั้นตอนที่ 1: เตรียมไฟล์ บันทึกโค้ดหน้านี้เป็นไฟล์ชื่อ index.html
ขั้นตอนที่ 2: สร้าง Repository 1. สมัคร/เข้าสู่ระบบ GitHub.com
2. กดปุ่ม + (New repository)
3. ตั้งชื่อ Repository เช่น my-portfolio แล้วกด Create Repository
ขั้นตอนที่ 3: อัปโหลดไฟล์ 1. ในหน้า Repository กดปุ่ม uploading an existing file
2. ลากไฟล์ index.html วางลงในช่องอัปโหลด
3. กดปุ่ม Commit changes ด้านล่าง
ขั้นตอนที่ 4: เปิดใช้งาน GitHub Pages 1. ไปที่เมนู Settings ของ Repository นั้น
2. เมนูด้านซ้ายเลือก Pages
3. ตรงหัวข้อ Build and deployment ให้เปลี่ยน Branch จาก None เป็น main แล้วกด Save
4. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์พร้อมใช้งาน!
